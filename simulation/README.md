## Running
This simulation is written in [Rust](https://www.rust-lang.org/). It uses the [iced](https://iced.rs/) GUI library.

You can run it with `cargo run`:
```
cargo run
```

The web version can be run with [`trunk`](https://trunkrs.dev/):

```bash
trunk serve
```
