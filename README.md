# Project Overview

## Abstract
This is my semester 2 final project in my multivariable calculus class in 12th grade in Amador Valley High School. This project teaches people about using integrals to get velocity and position as a function of time. It is meant to introduce integrals to people and demonstrate how they are useful. The scenario used in this presentation is two cars driving on the same lane, with the car in front suddenly braking. 

## Why I chose this topic
The project instructions are to make "an engaging presentation that reveals “the secrets of the universe” through calculus". When I think of “secrets of the universe” I think about physics. I was considering doing something related to minimizing costs but I think physics is closer to the instructions. There is velocity and acceleration, but everyone learns about derivatives with velocity and acceleration, so I didn’t just want my presentation to be “hey, this is a derivative”. I also wanted to keep things relatively simple since I’m planning on presenting to an algebra 1 class. I want the audience to appreciate how calculus is used to keep people safe and be able to make good judgements when driving based on changing factors.
